# Discord-бот: переводчик новостей EN -> RU

## Файлы
- bot.py — сам бот (запускать не нужно руками: хостинг сделает это сам)
- requirements.txt — список библиотек (хостинг установит сам)

## Токен
Токен НЕ хранится в коде! На хостинге найди раздел переменных окружения
(Environment Variables / Secrets / Переменные) и добавь:

  DISCORD_TOKEN = твой_токен_бота

Также можно добавить:
  SOURCE_CHANNEL_ID — ID промежуточного канала (куда приходят новости)
  TARGET_CHANNEL_ID — ID основного канала (куда бот отправляет перевод)

## После запуска
На сервере напиши /check — бот покажет статус. Если промежуточный канал
не привязан, напиши /bind и выбери два канала.
